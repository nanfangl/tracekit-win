TraceKit 软件行为记录器 · 使用说明
========================================

一、什么都不用装，双击 TraceKit.exe
------------------------------------
双击后是一个窗口，从上往下填四步：

  1. 选要记录的软件        → 点「浏览…」选它的 .exe
  2. 额外监视的数据目录    → 它往哪儿写配置/日志/导出，就点「添加目录…」加进来（可多个）
  3. 抓什么（九个勾选项）  → 取消勾选就省资源
        文件副本 / 界面结构 / DLL 模块加载 / 系统改动 / 主机名反查 /
        界面文字 / 按键与点击响应 / 日志文件内容 / 内核 ETW（需管理员）
       下面还能设：截图（间隔秒）、记录时长（0 = 录到它自己退出）、监视整个盘
       上面有三个预设按钮：省资源 / 标准 / 全量，一键切换整套勾选
  4. 点「开始记录」

记录期间会弹一个置顶小窗：显示「已记录 N 秒」+ 各类事件计数（文件/注册表/网络/模块…），
随时点「停止并出报告」就能提前收尾；录完会自动生成报告并问你要不要打开时间线。

输出在 EXE 旁边的 runs\<软件名>-<日期时间>\ 里，全部中文文件名：

  报告.md        中文分析报告（进程/文件/注册表/网络/界面/按钮响应/日志/时间线 + 扩展采集面汇总）
  时间线.html    单文件交互式时间线，双击用浏览器打开就能搜索、过滤、看截图
  日志汇总.txt   目标的日志全文 + 你每次点击/按键之后的程序响应
  界面结构.txt   每个窗口的结构：菜单栏全部菜单项（含 id）、控件树（类/ID/文字/坐标/是否可见禁用）
  模块清单.txt   目标加载过的每个 DLL（含中途退出的进程）：基址、大小、首次/末次时间
  系统改动.txt   记录期间服务 / 自启动项 / 计划任务 / 启动文件夹的新增、删除、修改
  文件副本\      它生成或改写的文件本体副本（SHA1 去重，单文件 2MB、总量 200MB 上限）
  剪贴板图片\    剪贴板里的图片
  截图\          截图 PNG
  崩溃信息.txt   目标崩溃时留下的转储/报告证据（有才生成）
  events.jsonl   原始事件流（一行一条，可用文本工具查）
  events.sqlite  原始事件库（可 SQL 统计）
  stdout.log     目标的标准输出（有的话）

所有给人看的文件都是 UTF-8 带 BOM，记事本 / WPS / Word 直接打开不会乱码。


一·补：不想用向导时，命令行也一样（同一个 EXE）
------------------------------------------------
  TraceKit.exe run --profile light  ...   只录基础面（进程/文件/注册表/网络/窗口/日志），最省资源
  TraceKit.exe run --profile standard ... 默认：再加界面结构、DLL、系统改动、主机反查、文件副本
  TraceKit.exe run --profile full   ...   全开（含按键/响应/界面文字/内核 ETW）

  额外监视整个盘：   --watch-drive D
  U 盘/移动硬盘：    默认自动监视，关掉用 --no-removable
  只想要文件本体：    --keep-max-mb 10 --keep-total-mb 2000
  已经开着的程序：    TraceKit.exe attach --title 软件标题 --duration 300



二、它能记录什么
----------------
· 进程：目标 + 它派生的所有子进程，含完整命令行、工作目录、存活时长
· 文件：创建 / 修改 / 删除 / 改名；做管理员时还能记「哪个进程读了哪个文件、写了多少字节」
· 注册表：键和值的新建、删除、修改，旧值→新值都留着
· 网络：每个连接/监听，本地→远端 IP:端口、状态迁移、断开
· 界面：窗口焦点切换、新弹窗、屏幕截图
· 界面文字：软件自己界面里的日志框/文本框内容，变化一次记一次
· 按钮响应：点了哪个按钮（标题、控件ID、所属窗口、连击次数），以及点击后 0.7 秒内
            哪些控件变了（复选框勾选、下拉选择、日志框新文字、新开的窗口）
· 按键：全局按键（含实际字符、修饰键、是否程序模拟），以及每次按键落在哪个控件上
· 日志文件：它写的 .log/.txt/.ini 等文本文件，逐行增量记录内容
· 剪贴板：变化时的文本内容


三、对「易语言 + VMP 加壳」的目标为什么有效
-------------------------------------------
记录是"从外面看"：内核层的文件/注册表/网络事件、系统的窗口与输入钩子、系统消息读取控件文字。
全程不注入目标进程、不修改它的代码、不附加调试器，所以 VMP 的反调试/自校验不会被触发。
易语言是 32 位程序，命令行读取走 WOW64 分支，界面日志框用 WM_GETTEXT 直接读出文字。


四、常见问题
------------
Q: 提示不是管理员？
A: 右键 → 以管理员身份运行。不做管理员也能录，但记不到"谁读了文件"，也读不到目标命令行。

Q: 想要更久/更短？
A: 向导里填记录秒数；留空就是录到目标自己退出。

Q: 只想录某一小段时间，软件是别人已经打开的？
A: 命令行：TraceKit.exe attach --title 软件标题 --duration 300

Q: 报告里没看到我要的东西？
A: 用 时间线.html 全量搜索（默认按类别过滤显示），或在 events.jsonl 里直接搜关键字。

Q: 自己的东西，先试一下？
A: 命令行跑 TraceKit.exe selftest，它会用内置的演示程序（TraceKitDemo.exe）走一遍全流程，
   逐项告诉你 11 个记录层是否都拿到了数据。
